# TableTheory v6.4.0

## Dependency refresh

TableTheory 6.4.0 refreshes the Go dependency graph to the versions delivered by the
November 2026 Dependabot bundle. The root module, the contract-test runner, and every
example module move together, so each module resolves the same AWS SDK for Go v2
versions.

There is no API change and no stored-representation change. Key encoding, marshalling,
and the attributes written are unchanged; the frozen contract fixtures and the
key-parity suite pass without modification, and no data migration is required.
Consumers need no code changes: refresh as usual.

The one behavior-visible dependency delta is
`github.com/aws/aws-sdk-go-v2/service/dynamodbstreams` 1.43.0 to 1.46.6, which adds the
`AT_TIMESTAMP` shard-iterator type and fixes nil list/map deserialization. TableTheory
uses that module only in the local examples harness (describe stream, trim-horizon
iterator, get records); the storage path never calls it, so no TableTheory call site
changes.

No TypeScript or Python API change accompanies this release.
